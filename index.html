폐루프 속도 제어

출력값이 아닌, 실제 회전속도를 기준으로.

01 / MEASURE

현재 RPM 계산

일정 시간 동안의 엔코더 카운트 변화량을 읽어 바퀴의 회전속도를 계산합니다.

RPM = Δcount × 60counts/rev × Δt
Δt: 측정 간격 [s]
02 / COMPARE

목표와 실제 값 비교

수신한 조이스틱 값을 좌우 목표 RPM으로 변환하고, 각각의 현재 RPM과 비교해 오차를 구합니다.

error_L = target_L − rpm_L
error_R = target_R − rpm_R
03 / CONTROL

PID 출력 적용

각 바퀴의 오차를 PID 제어기에 전달합니다. 계산한 출력으로 PWM과 방향을 제어하고 다시 속도를 측정합니다.

목표 → 오차 → PID → PWM
